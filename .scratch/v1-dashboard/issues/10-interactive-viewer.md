# Interactive viewer plugin and launcher

Status: ready-for-agent
Blocked by: 07

KOReader plugin: full-screen PNG from the server, tap regions from the screen JSON, pending state on tap, then the new PNG. Minute clock refresh while open. Stock-home launcher scriptlet that runs `koreader.sh --asap` straight into the viewer, detached with `setsid`. Measure tap-to-dashboard time and Wi-Fi reconnect after a tap.
